Your shell, but smart.

Project Yena makes your linux or mac terminal smarter, by bridging the gap between natural language and complex system operations. Powered by your preferred local AI models and working seamlessly with the Fish Shell, it currently features two modules designed to assist with command generation and deep file analysis. AI Command Assistant

Translates your English intent into precise, single-line Fish commands. Yena formats the output with Rich for beautiful TUI rendering and prompts you to Execute or Edit the command directly using gum.

  • Deep Search (-d): Hooks into SearXNG to browse the web for up-to-date CLI documentation before generating a command.
  • History Recall (-r): Analyzes your last 100 Fish history entries to provide highly contextual commands.

AI File Helper

Chat directly with your local files. Yena uses fd for fuzzy finding your target and dynamically adopts a persona—becoming an Architect for source code or a Scholar for general text files.

  • Broad Extraction: Reads raw code, markdown, and natively handles document parsing via pdftotext and pandoc (for EPUB/DOCX).
  • Built-in Subcommands: Use sum for instant bulleted summaries or meta to reveal rich file stat metadata (permissions, octal codes, ownership).

Unified Installation

Yena is designed for a seamless setup. The installer script automatically provisions a Python virtual environment, installs dependencies, and creates symbolic links to your Fish config directory.

# 1. Clone the repository git clone https://github.com/your-username/project-yena.git cd project-yena
# 2. Run the unified installer ./install_yena.fish
# 3. Reload your shell exec fish
